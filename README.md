# Lund Winter Park Planner

Interactive map: which of Lund's neighbourhood parks (≥ 1 ha) people can use on a dark December evening — paths cleared of snow and lit — and which fixes help the most residents.

Live site: https://rafaneo.github.io/lund-winter-planner/

Built for the SESAC hackathon 2026 (Lund). This repository contains only the built website; the analysis lives in a separate private repository.

Data: © OpenStreetMap contributors (ODbL); Lund kommun winter maintenance map; SCB population (CC0); European Commission JRC GHS-POP 2025 (CC BY 4.0); Green Urbansights height model and land cover (organiser data, SESAC hackathon). Sun model: team shadow model, clear sky, 21 December.
Built with React, Vite, Tailwind CSS, shadcn/ui, ReUI, MapLibre GL and Recharts.
